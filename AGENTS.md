# Заметки для агентов

Проект — genOferta: сборка объединённых изменений в публичную оферту
«Удобный доступ» и обновление её текста с выделением правок.

## Принципы

- **Юридический текст Оферты меняет только детерминированный движок** (`lib/`),
  строго по подтверждённым операциям. ИИ (OpenRouter) — исключительно парсер
  инструкций в структурный JSON; он не переписывает документ.
- Правки OOXML — **хирургические над сырой XML-строкой** (`lib/ooxml.ts`), без
  полного разбора/пересборки дерева, чтобы сохранять исходный docx байт-в-байт.
- Всё, что уходит в репозиторий (код, коммиты, комментарии), — без указания
  конкретной модели ИИ.

## Проверка

- `npm run engine:demo` — E2E-прогон движка на `fixtures/` без ключа ИИ.
- `npm run build` и `npm run lint` — обязательны перед коммитом.
